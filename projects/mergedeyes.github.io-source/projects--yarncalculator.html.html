<h1 class="heading-element" dir="auto">Yarn Composition Calculator / Garn-Zusammensetzungs-Rechner</h1>
<p dir="auto"><a href="#-english-documentation">🇬🇧 English Documentation</a> | <a href="#-deutsche-dokumentation">🇩🇪 Deutsche Dokumentation</a></p>
<hr/>
<p dir="auto"><a name="user-content--english-documentation"></a></p>
<h2 class="heading-element" dir="auto">🇬🇧 English Documentation</h2>
<p dir="auto">A robust Java Swing application designed for textile enthusiasts, knitters, and designers. It calculates the exact fiber composition of a project that combines multiple different yarns with varying weights and blends.</p>
<h3 class="heading-element" dir="auto">📋 Prerequisites</h3>
<ul dir="auto">
<li><strong>Java Development Kit (JDK) 25</strong> or higher.
<ul dir="auto">
<li>This application leverages modern Java features. Please ensure you have the latest JDK installed.</li>
<li>Download: <a href="https://adoptium.net/" rel="nofollow">Adoptium (Eclipse Temurin)</a> or <a href="https://www.oracle.com/java/technologies/downloads/" rel="nofollow">Oracle</a>.</li>
</ul>
</li>
<li><strong>Fiber names: <a href="https://eur-lex.europa.eu/legal-content/DE/TXT/?uri=CELEX%3A02011R1007-20180215" rel="nofollow">https://eur-lex.europa.eu/legal-content/DE/TXT/?uri=CELEX%3A02011R1007-20180215</a></strong></li>
</ul>
<h3 class="heading-element" dir="auto">🚀 How to Run (For Windows, skip this step)</h3>
<ol dir="auto">
<li>Download the <code>GarnRechnerProzedural.java</code> file.</li>
<li>Open your terminal or command prompt.</li>
<li>Navigate to the directory containing the file.</li>
<li>Compile the code:
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="javac GarnRechnerProzedural.java" dir="auto"><pre>javac GarnRechnerProzedural.java</pre></div>
</li>
<li>Run the application:
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content="java GarnRechnerProzedural" dir="auto"><pre>java GarnRechnerProzedural</pre></div>
</li>
</ol>

<h3 class="heading-element" dir="auto">✨ Features</h3>
<ul dir="auto">
<li><strong>Multi-Yarn Calculation:</strong> Add as many yarn sources as needed. The interface automatically numbers them (Yarn 1, Yarn 2, etc.) and uses a thick border to distinguish them.</li>
<li><strong>Weighted Calculation:</strong> Enter the specific weight (in grams) for each yarn to get a mathematically accurate total composition based on the ratio of materials.</li>
<li><strong>Template System (JSON):</strong>
<ul dir="auto">
<li><strong>Yarn Templates:</strong> Save your favorite yarn blends (e.g., "Sock Wool Classic") to a local file and reuse them later.</li>
<li><strong>Fiber Database:</strong> Manage a list of fiber types (Wool, Cotton, Silk, etc.) in a dropdown menu. You can add new ones or delete existing ones directly from the UI.</li>
</ul>
</li>
<li><strong>Smart Editing:</strong>
<ul dir="auto">
<li><strong>Locking:</strong> Predefined templates are locked by default to prevent accidental changes.</li>
<li><strong>Edit Mode:</strong> Clicking <strong>"Edit Yarn"</strong> unlocks the fields and switches the dropdown to <strong>"New"</strong>, allowing you to modify a preset without overwriting the original unless desired.</li>
<li><strong>Save/Overwrite:</strong> Use <strong>"Save Yarn"</strong> to store new templates or overwrite existing ones.</li>
</ul>
</li>
<li><strong>Precision Rounding:</strong> The app uses the <strong>Largest Remainder Method</strong> (Hare-Niemeyer) to ensure the calculated percentages always sum up to exactly <strong>100.0%</strong>. It minimizes statistical rounding errors better than standard rounding.</li>
<li><strong>Excel Export:</strong> The result dialog includes a <strong>"Copy"</strong> button. This puts the data into your clipboard in a format optimized for pasting directly into Excel, Google Sheets, or other spreadsheet software (Tab-separated values).</li>
<li><strong>Bilingual Interface:</strong> Toggle between <strong>English (EN)</strong> and <strong>German (DE)</strong> instantly via the buttons in the top-right corner.</li>
</ul>
<h3 class="heading-element" dir="auto">📖 Usage Guide</h3>
<ol dir="auto">
<li><strong>Add Yarn:</strong> Click <strong>"Add Yarn"</strong> to create a new input block.</li>
<li><strong>Select Template:</strong>
<ul dir="auto">
<li>Choose a saved yarn from the dropdown menu to auto-fill fibers.</li>
<li>Or select <strong>"New"</strong> to define a custom blend.</li>
</ul>
</li>
<li><strong>Enter Weight:</strong> Input the weight in <strong>"Grams"</strong> used for this specific yarn.</li>
<li><strong>Define Fibers:</strong>
<ul dir="auto">
<li>Select a fiber from the dropdown or type a new name.</li>
<li>Enter the percentage for that fiber.</li>
<li><strong>Buttons:</strong>
<ul dir="auto">
<li><strong><code>S</code> (Save):</strong> Saves the currently typed fiber name to the global dropdown list.</li>
<li><strong><code>D</code> (Delete):</strong> Removes the selected fiber type from the global dropdown list.</li>
<li><strong>"Remove Fiber":</strong> Removes the specific fiber row from the current yarn.</li>
</ul>
</li>
<li><strong>Fill Rest:</strong> Click <strong>"Fill Rest to 100%"</strong> to automatically calculate the remaining percentage for the last row.</li>
</ul>
</li>
<li><strong>Calculate:</strong> Click the <strong>"Calculate"</strong> button at the bottom.</li>
<li><strong>Export:</strong> In the result window, click <strong>"Copy"</strong> to put the table into your clipboard.</li>
</ol>

<h3 class="heading-element" dir="auto">✨ Funktionen</h3>
<ul dir="auto">
<li><strong>Mehrfach-Garn-Berechnung:</strong> Fügen Sie beliebig viele Garnquellen hinzu. Die Oberfläche nummeriert diese automatisch (Garn 1, Garn 2, usw.) und hebt sie durch einen dicken Rahmen hervor.</li>
<li><strong>Gewichtete Berechnung:</strong> Geben Sie das spezifische Gewicht (in Gramm) für jedes Garn ein, um eine mathematisch exakte Gesamtzusammensetzung basierend auf dem Materialverhältnis zu erhalten.</li>
<li><strong>Vorlagen-System (JSON):</strong>
<ul dir="auto">
<li><strong>Garn-Vorlagen:</strong> Speichern Sie Ihre bevorzugten Garnmischungen (z. B. "Sockenwolle Klassik") in einer lokalen Datei, um sie später wiederzuverwenden.</li>
<li><strong>Faser-Datenbank:</strong> Verwalten Sie eine Liste von Faserarten (Wolle, Baumwolle, Seide usw.) in einem Dropdown-Menü. Sie können neue Arten hinzufügen oder bestehende löschen.</li>
</ul>
</li>
<li><strong>Intelligentes Bearbeiten:</strong>
<ul dir="auto">
<li><strong>Sperre:</strong> Vordefinierte Vorlagen sind standardmäßig gesperrt, um versehentliche Änderungen zu verhindern.</li>
<li><strong>Bearbeiten-Modus:</strong> Ein Klick auf <strong>"Garn Bearbeiten"</strong> entsperrt die Felder und wechselt in den Modus <strong>"Neu"</strong>, sodass Sie eine Mischung anpassen können, ohne das Original zu überschreiben (es sei denn, Sie wünschen dies).</li>
<li><strong>Speichern/Überschreiben:</strong> Mit <strong>"Garn Speichern"</strong> können Sie neue Vorlagen sichern oder bestehende nach einer Bestätigung überschreiben.</li>
</ul>
</li>
<li><strong>Präzises Runden:</strong> Die App verwendet das <strong>Hare-Niemeyer-Verfahren</strong> (Largest Remainder Method), um sicherzustellen, dass die Endsumme der Anteile immer exakt <strong>100,0 %</strong> beträgt. Dies minimiert statistische Rundungsfehler besser als herkömmliches Runden.</li>
<li><strong>Excel-Export:</strong> Das Ergebnisfenster enthält einen <strong>"Kopieren"</strong>-Button. Dieser kopiert die Tabelle in die Zwischenablage in einem Format, das direkt in Excel oder Google Sheets eingefügt werden kann.</li>
<li><strong>Zweisprachige Oberfläche:</strong> Wechseln Sie über die Buttons oben rechts sofort zwischen <strong>Englisch (EN)</strong> und <strong>Deutsch (DE)</strong>.</li>
</ul>

<ul dir="auto">
<li>Wählen Sie ein gespeichertes Garn aus dem Dropdown-Menü, um die Fasern automatisch auszufüllen.</li>
<li>Oder lassen Sie die Auswahl auf <strong>"Neu"</strong>, um eine eigene Mischung zu definieren.</li>
</ul>
</li>
<li><strong>Gewicht eingeben:</strong> Tragen Sie das Gewicht in <strong>"Gramm"</strong> ein, das von diesem Garn verwendet wird.</li>
<li><strong>Fasern definieren:</strong>
<ul dir="auto">
<li>Wählen Sie eine Faser aus dem Dropdown oder tippen Sie einen neuen Namen ein.</li>
<li>Geben Sie den prozentualen Anteil ein.</li>
<li><strong>Buttons:</strong>
<ul dir="auto">
<li><strong><code>S</code> (Speichern):</strong> Speichert den aktuell eingetippten Fasernamen in die globale Dropdown-Liste.</li>
<li><strong><code>D</code> (Löschen):</strong> Entfernt die ausgewählte Faserart aus der globalen Liste.</li>
<li><strong>"Faser Entfernen":</strong> Entfernt die spezifische Faserzeile aus dem aktuellen Garn.</li>
</ul>
</li>

</ol>
