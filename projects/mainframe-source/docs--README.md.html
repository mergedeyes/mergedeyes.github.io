Mainframe documentation

Mainframe is a file browser for the terminal that also builds, runs, tests, installs, deploys and releases your projects. These pages describe what it does today, on Linux.

Getting started

  • Introduction: what Mainframe is, how the screen is laid out, which projects it understands
  • Installation: build it, optional tools, cd on exit
  • First steps: a ten-minute tour, from opening a project to running its tests

Guides

  • Files: moving around, finding files, creating, renaming, copying, deleting
  • Running things: build, run, test, the task picker, output tabs, watch mode, jumping to errors
  • Git: the git menu, committing, branches, worktrees, GitHub repos and releases
  • Projects, notes and Claude: the project picker, notes and todos, new projects, the CLAUDE.md preset
  • Installing and deploying: putting a binary on your PATH, deploying to a Raspberry Pi or a server
  • Cleaning up: getting disk space back from build output, dependencies and caches

Reference

  • Keys: every key, in every view
  • Configuration: config.toml, custom actions, per-project settings and deploy targets
