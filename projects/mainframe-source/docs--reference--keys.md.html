Keys

Every key, by view. Inside Mainframe, ? shows the most important ones. Custom actions from the configuration come first: a custom action on a key replaces what the key does here.

File list

Moving

Key What it does
j k, ↓ ↑ down, up
l, → open the folder
h, ←, Backspace parent folder
PgDn PgUp a page down, up
Ctrl-D Ctrl-U half a page down, up
Home End first, last entry
Enter open a folder, edit a text file, run a program, open anything else with the default app
/ filter the list; Enter keeps it, Esc clears it
c go to a path, or zoxide keywords
Z zoxide's picker
Ctrl-P find a file in the project
J project picker
~ home folder
. show or hide hidden files
S sort by name, newest first, largest first
Ctrl-R reload
Esc clear the filter, then the marks

Files

Key What it does
a new file
A new folder
m, F2 rename or move
d, Delete move to the trash
Space mark (for y, d, s, u)
y yank the marked or selected entries
p / P paste a copy / move here
s / u git stage / unstage

Key What it does

+ - output pane bigger, smaller

Output pane, focused (Tab)

Key What it does

PgDn PgUp a page
Home End top, bottom (End follows new output)

Esc clear the search, then back to the file list

Prompts

The footer prompts (:, c, a, m, commit message …):

Key What it does
Tab / Shift-Tab complete; again to cycle through the suggestions
↓ ↑ step through the suggestions; in : without suggestions, the command history
Enter done
Esc, Ctrl-C cancel

Tab completes paths, programs on your PATH in :, zoxide matches in c, and branch names where a branch is asked for.

Forms

The forms for new projects, deploy targets, releases and GitHub repos go field by field. Every field has a default.

Key What it does
typing replaces the default
Enter, ↓, Tab next field (the default stays when you didn't type)
↑, Shift-Tab previous field; Backspace too, in an empty field
← → or Space change a choice
Enter or y on the last step go
Esc, Ctrl-C cancel
Ctrl-T in the new-project form: edit your CLAUDE.md template

Git menu (g)

s status · d D diff, staged diff · l log · L file history · w blame · a A stage selected, all · u unstage · c commit · C stage all and commit · e amend · x discard changes · f fetch · p pull · P push · B push another branch · b branches · o switch branch · n new branch · W remove a worktree · z Z stash, pop · r release · R releases and CI · i init · h GitHub repo · g lazygit, gitui or tig. See Git.

Pickers

Project picker (J): type to filter · Enter go · Ctrl-T notes · Ctrl-O VS Code · Ctrl-G new project · Ctrl-L CLAUDE.md preset · Esc close

Branch picker (g o): type to filter · Enter switch · Esc close. Numbered in merge order; see Git.

Task picker (T): type to filter · Enter run · Ctrl-R run in the full terminal · Esc close

File finder (Ctrl-P): type to filter · Enter show in the list · Ctrl-E edit · Esc close

In these three, ↓ ↑, Tab Shift-Tab and Ctrl-N Ctrl-P move.

Install picker (i): Enter or i install · p pull, then install · r run · d desktop entry · u remove a copy that shadows it on PATH · Esc close

Desktop entry review: Enter or y update · n skip · j k scroll · Esc cancel all

Deploy picker (D): Enter or D deploy · u roll back · l list backups · a add a target · e edit the target · x delete it · E the settings file in your editor · Esc close

Cleanup (C): Space mark · a mark all like this · Enter delete · Esc close

Notes (M)

Key What it does
j k, ↓ ↑ move
g G, Home End first, last line
a or o add a todo
n add a note line
Enter, e or i edit the line
Space or x check a todo off, or on
t todo ⇄ note
d, Delete delete
u undo
J K move the line down, up
C remove checked todos
E the whole file in your editor
Esc, q or M close

Blog (L)

Only in the blog repo set with blog_repo in the configuration, or in a worktree of it; anywhere else L does nothing. See Blog.

Key What it does
j k, ↓ ↑ move
g G, Home End first, last post
Enter, e write in the built-in post editor
E edit in your own editor instead; the picker comes back afterwards
a new post: title, description, draft or post now; then the post editor
n the /now page in the post editor; writes now.md first when there's none
p publish a draft: move it to _posts/ with today's date, commit and push (asks first)
P commit and push your changes to a post; on the /now page, set updated: to today first
u unpublish: move a post back to _drafts/, no commit
d, Delete move to the trash (asks first)
/ filter; Enter keeps it, Esc clears it
Esc, q or L close (Esc clears a filter first)

Post editor

Title and description on top, the Markdown on the left, a preview on the right (in windows at least 90 columns wide). It saves by itself a moment after you stop typing, and when you close it.

Key What it does
Enter, Tab, ↓ / Shift-Tab, ↑ next / previous field; ↑ on the first line of the text goes back to the description
arrows, Home End, PgUp PgDn move; up and down go by screen row in wrapped lines
Ctrl ← → a word left, right
Ctrl-Home Ctrl-End start, end of the text
Ctrl-W, Ctrl-Backspace delete the word before the cursor
Enter new line; in a list or quote it continues it, on an empty item it ends the list
Tab / Shift-Tab indent / outdent a list item (elsewhere: four spaces)
Ctrl-B / Ctrl-E the word in **bold** / _italic_, or an empty pair to type into
Ctrl-K the word as a link, [word](), cursor in the parentheses
Ctrl-Z / Ctrl-Y undo / redo
Ctrl-S save now (also over changes made outside Mainframe)
Ctrl-R reload the file from disk
Ctrl-P preview on or off
Ctrl-G a draft: publish it (asks first); a post: commit and push your changes; the /now page: set updated: to today, commit and push
Esc, Ctrl-Q save and close, back to the picker
